# نظام مبايعات السيارات

نظام ويب كامل لإدارة عقود بيع السيارات: مستخدمين بصلاحيات (مدير / موظف مبيعات)، مخزون سيارات (إضافة يدوية أو رفع ملف إكسل)، إنشاء عقد مبايعة يبحث عن السيارة بآخر أرقام الهيكل، وموافقة المدير قبل السماح بطباعة العقد النهائي.

## المتطلبات
- Node.js 18 أو أحدث
- قاعدة بيانات PostgreSQL

## التشغيل محليًا

```bash
npm install
cp .env.example .env
# عدّل ملف .env: ضع رابط قاعدة بياناتك المحلية، وخلي DATABASE_SSL=false لو بتشتغل على قاعدة بيانات محلية بدون SSL
npm start
```

بعد التشغيل، افتح المتصفح على `/setup` لإنشاء أول حساب مدير باستخدام قيمة `SETUP_TOKEN` الموجودة في `.env`. بعد إنشاء أول مستخدم، هذه الصفحة تتعطل تلقائيًا.

## النشر على Railway

1. من لوحة Railway أنشئ مشروع جديد واختر **Deploy from GitHub repo** ثم اختر الريبو.
2. أضف قاعدة بيانات: من نفس المشروع اضغط **New → Database → PostgreSQL**. Railway هيضيف متغير `DATABASE_URL` تلقائيًا لخدمة الويب لو ربطتهم مع بعض (Variable Reference).
3. من تبويب **Variables** لخدمة الويب أضف:
   - `SESSION_SECRET` — نص عشوائي طويل
   - `SETUP_TOKEN` — نص سري تستخدمه مرة واحدة لإنشاء أول حساب مدير
   - `DATABASE_SSL` — سيبها `true` (القيمة الافتراضية) لأن Railway Postgres يحتاج SSL
4. Railway هيقرأ ملف `Procfile` ويشغل `node server.js` تلقائيًا. تأكد إن **Start Command** فاضي أو مطابق لمحتوى الـ Procfile.
5. بعد نجاح النشر، افتح رابط التطبيق ثم اذهب لمسار `/setup` لإنشاء أول حساب مدير.

## طريقة الاستخدام

1. **بيانات الشركة** (تبويب متاح للمدير فقط): يدخل المدير اسم الشركة، السجل التجاري، الرقم الضريبي، الهاتف، العنوان، والفرع — تُستخدم تلقائيًا في كل عقد.
2. **المستخدمون** (للمدير فقط): إنشاء حسابات لموظفي المبيعات، وتفعيل/إيقاف أي حساب.
3. **مخزون السيارات**: إضافة سيارة يدويًا، أو رفع ملف إكسل بالجملة. اضغط "تحميل قالب الإكسل" للحصول على نموذج بالأعمدة الصحيحة (رقم الهيكل، الماركة، الموديل، سنة الصنع، اللون، رقم اللوحة، السعر، ملاحظات). رفع نفس رقم الهيكل مرة أخرى يقوم بتحديث بيانات السيارة بدل تكرارها.
4. **عقد جديد**: يبحث الموظف بآخر أرقام الهيكل، تظهر بيانات السيارة تلقائيًا، يعبي بيانات العميل والسعر والشروط، ويرسل العقد — يظهر بحالة "بانتظار الموافقة".
5. **موافقة المدير**: المدير يفتح العقد من قائمة العقود ويضغط "اعتماد" أو "رفض". عند الاعتماد تتحول السيارة لحالة "مباعة" تلقائيًا.
6. **طباعة العقد**: زر "طباعة العقد المعتمد" يظهر فقط بعد اعتماد المدير، ويفتح نسخة نظيفة للطباعة أو الحفظ كـ PDF من متصفح المستخدم (Ctrl+P).

## ملاحظات أمان
- كل كلمات المرور مشفّرة (bcrypt) قبل حفظها.
- الجلسات (Sessions) صالحة لمدة 8 ساعات ثم تنتهي تلقائيًا.
- صفحة `/setup` تتوقف عن العمل بعد إنشاء أول مستخدم في النظام، حتى لو عرف حد التوكن بعدين.
